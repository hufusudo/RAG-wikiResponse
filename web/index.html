模型与 API Key 设置

支持 OpenAI 兼容接口（DeepSeek / OpenAI / 智谱 / 通义 / 硅基流动 等）。只需填 Key 与 Base URL，保存后自动获取可用模型，可在输入框左侧随时切换。

选择 Vault 文件夹

进入目录后点「选择此文件夹」；含笔记的仓库目录即可作为 Vault（隐藏目录可在路径栏手输进入）。

回答风格 Prompt（当前仓库全局）

这段文字会附加进每次问答的系统提示，用于固定回答风格（语气、篇幅、推导详略、复习面向…）。 仅对当前打开的仓库生效，仓库内所有会话通用；不影响 Wiki 卡片提炼。

帮助

批量初始化 · Token 消耗确认

⚠️ 批量初始化会逐篇调用 LLM，笔记越多消耗越大。 单篇输入上限 12,000 字符（超长自动截断），上下文不会因笔记总数变大而爆炸， 但总 Token 消耗随篇数线性增长。
💡 不是必须批量：不初始化也能问答（冷启动按 raw 标题兜底检索）； 问答命中未覆盖的知识点时，Lazy 飞轮会自动补卡——Token 只花在被问过的知识上。
